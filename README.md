## 📌 Project Overview

This project is a multi-page static landing page created for **Task 1** of the **Oasis Infobyte Internship (OIBSIP)**. It showcases **Roast & Ground**, an artisan specialty coffee brand that ethically sources and roasts 100% single-origin shade-grown Indian Arabica beans from renowned estates across Chikmagalur, Coorg, and Araku Valley.

The project features semantic HTML5 structure, modern CSS3 layout techniques (Flexbox and Grid), responsive design across mobile, tablet, and desktop devices, and multi-page navigation without any JavaScript or external frameworks.

---

## 🚀 Key Features

1. **Multi-Page Architecture**:
   - Each navbar item opens its own dedicated page with page loading and active state indicators:
     - `index.html`: Main landing page with hero, value highlights, and curated sections.
     - `features.html`: Deep dive into roasting standards, certifications, and an in-depth Quality Comparison Table.
     - `about.html`: Heritage story, ethical farmer partnerships, 3 guiding principles, and a featured quote by celebrated Indian author **Ruskin Bond**.
     - `blends.html`: Full catalogue of 6 artisan coffee blends with roast badges, tasting notes, and Indian Rupee (`₹`) pricing.
     - `reviews.html`: Overall 4.9/5 star community rating scorecard, verified metrics, and customer testimonials from across India.
     - `contact.html`: Interactive contact form, roastery & tasting room address (Brigade Road, Bengaluru), email, phone, and visiting hours.

2. **Responsive Mobile Navigation (Pure CSS)**:
   - Floating header with sticky positioning.
   - Interactive CSS checkbox-based animated hamburger icon that smoothly morphs into an "X" close icon on mobile screens.
   - Touch-friendly card-style menu links with active state styling.

3. **Authentic Indian Localization**:
   - All pricing standardized in **Indian Rupees (₹)**: `₹499`, `₹549`, etc.
   - Coffee origins highlight famous Indian coffee regions: **Chikmagalur (Karnataka)**, **Coorg (Karnataka)**, **Malabar Coast (Kerala)**, and **Araku Valley (Andhra Pradesh)**.
   - Inspirational quote by **Ruskin Bond** celebrating morning coffee rituals and quiet reflection.

4. **100% Clean Code & Compliance**:
   - Zero JavaScript (pure HTML5 & CSS3).
   - Zero external libraries or UI kits.
   - Zero comments throughout the codebase for a clean, beginner-accessible structure.
   - No horizontal scrollbars or element overlap on mobile devices.

## 💻 How to Run Locally

No build tools, package managers, or server installations are required:

1. Clone the repository:
   ```bash
   git clone https://github.com/mr-ankush876/OIBSIP.git
   cd OIBSIP
   ```
2. Open `index.html` directly in any web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari) by double-clicking the file.
3. Alternatively, if using VS Code, right-click `index.html` and select **"Open with Live Server"**.
