## ☕ Project Overview

Roast & Ground is an artisan roastery showcasing 100% single-origin, shade-grown Arabica coffee ethically sourced from renowned Indian coffee-growing estates across Chikmagalur, Coorg, and Araku Valley.

Built purely with semantic HTML5 and modern CSS3, it delivers a fast, responsive user experience with zero JavaScript dependencies.

---

## 🌟 Key Features

1. **Multi-Page Architecture (6 Dedicated Pages)**:
   - `index.html`: Hero banner, value metrics (12,000+ Happy Lovers, 48-hour roasting, 100% Fair Trade), and curated highlights.
   - `features.html`: Small-batch roasting standards and an in-depth Quality Comparison Table against commercial coffee brands.
   - `about.html`: Heritage story, 3 ethical sourcing principles, and an inspiring quote by acclaimed Indian author **Ruskin Bond**.
   - `blends.html`: Catalog of 6 artisan coffee blends with roast levels, tasting notes, and Indian Rupee (`₹`) pricing.
   - `reviews.html`: Overall 4.9/5 community rating scorecard, verified buyer badges, and detailed testimonials.
   - `contact.html`: Interactive tasting room inquiry form, physical roastery address (Brigade Road, Bengaluru), phone, and email.

2. **Responsive Pure CSS Mobile Navigation**:
   - Checkbox-hack powered animated mobile hamburger menu that morphs into a close icon without a single line of JavaScript.
   - Sticky top navigation bar with active page indicator pills.

3. **Authentic Indian Localization**:
   - Standardized pricing in Indian Rupees (`₹`).
   - Sourcing focus: Chikmagalur (Karnataka), Coorg (Karnataka), Malabar Coast (Kerala), and Araku Valley (Andhra Pradesh).
   - Roastery physical address situated in Ashok Nagar, Brigade Road, Bengaluru.

4. **Clean Code & Performance**:
   - 100% Pure CSS and Semantic HTML5.
   - Zero external libraries or bloated JavaScript.
   - System font typography stack for instant, latency-free rendering.
