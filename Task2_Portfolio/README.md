## 🌟 Key Features

1. **Multi-Page Architecture (5 Dedicated Pages)**:
   - `index.html`: Hero section with portrait photo, "Open for Work" floating status, live stats, skill summary, featured projects, and contact CTA.
   - `about.html`: Detailed biography, academic background (Computer Science undergraduate), engineering philosophy, and milestones.
   - `skills.html`: Comprehensive inventory across Web Technologies, Programming Languages (C, C++, Java, JS, Python), Databases (DBMS, SQL), and calibrated percentage proficiency bars.
   - `projects.html`: Showcase of 7 authentic GitHub repositories developed and maintained by Ankush Kumar (`@mr-ankush876`) with direct links and tech tags.
   - `contact.html`: Interactive direct inquiry form, verified contact channels (Email, Phone/WhatsApp, Location), and social connect links.

2. **Ultra-Modern Dark Mesh Glassmorphism UI**:
   - Deep canvas theme (`#090d16`) with cyan (`#00f0ff`) and indigo (`#4f46e5`) ambient radial glow gradients.
   - Frosted glass cards with translucent borders (`backdrop-filter: blur(16px)`).

3. **Custom Visual Assets & Identity**:
   - Standalone geometric **"AK" monogram logo** (`logo.png`) in header dock and footer.
   - High-resolution, executive **square portrait photo** (`profile.jpg`) with an animated pulsing status indicator badge.

4. **Minimalist Vector Navigation Dock**:
   - Sleek floating dock with custom SVG icons and pure CSS hover tooltips.
   - Active page states and accessible `aria-label` attributes throughout.

5. **Integrated Icon-Only Social Dock**:
   - Direct links to **GitHub**, **LinkedIn**, **X (Twitter)**, **Instagram**, and **Facebook** with custom brand hover glows and tooltips.

6. **Calibrated Skills Breakdown**:
   - Accurate visual progress bars reflecting actual coursework and project experience (HTML/CSS 95%, C/C++ 90%, OOP 88%, JS 85%, DBMS/SQL 82%, Java 80%, React 75%).

7. **Strict Code Quality Standard**:
   - Strictly zero comments throughout all HTML and CSS source files.
   - Clean, standard-compliant semantic markup.
